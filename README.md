# Covalia

Landing page del proyecto residencial **Covalia** (Temozón Norte, Mérida, Yucatán), un desarrollo de Desarrolladora Calume.

## Stack

- Next.js 14 (App Router, TypeScript)
- Tailwind CSS con la paleta de marca de Covalia (extraída del brochure): verde `#1D3A32`, crema `#F6EFE1`, ocre `#D08A3E`
- Sin backend: el formulario de contacto abre WhatsApp con los datos prellenados

## Desarrollo local

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm start
```
